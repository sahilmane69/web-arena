# WebArena Agent

A minimal WebArena-inspired starter project with a React frontend, Express API, and Python browser-agent entry point.

## Run locally

Install dependencies:

```bash
npm install --prefix frontend
npm install --prefix backend
```

Start each service in its own terminal:

```bash
npm run dev:frontend
npm run dev:backend
```

The frontend is served at `http://localhost:5173` and the API at `http://localhost:3001`.

## Project structure

- `frontend/` — React + Vite client
- `backend/` — Express API
- `agent/` — Python browser-agent placeholder

The Python agent currently only provides a runnable entry point; no browser automation has been added.
